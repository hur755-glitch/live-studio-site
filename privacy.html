1. 적용 범위

이 방침은 Live Studio Windows 프로그램과 이 소개 웹사이트에 적용됩니다. Live Studio는 YouTube API Services를 사용합니다. Google의 정보 처리에는 Google 개인정보처리방침이 별도로 적용됩니다.

2. 접근하고 저장하는 정보

  • Google OAuth 연결 정보: 액세스 토큰, 리프레시 토큰, 권한 범위, 유효기간 및 연결 상태.
  • YouTube API 데이터: 채널 ID 및 이름, 방송과 스트림의 식별자, 상태, 연결 정보 등 방송 관리에 필요한 정보.
  • 로컬 운영 정보: 사용자 입력 방송 설정·예약, 미디어 파일 경로, 송출 키, 작업 및 진단 기록.
  • 로컬 관리자 인증: 암호의 salt 및 해시, 인증 세션과 일회성 승인 보호 정보.

Google 계정 비밀번호는 Live Studio에서 수집하지 않습니다. Google 로그인은 Google의 인증 화면에서 이루어집니다.

3. 사용 목적 및 공유

정보는 연결 계정 식별, 채널·방송·스트림 조회, 사용자에게 승인된 방송 관리, 송출 및 오류 진단을 위해 사용합니다. Google 및 YouTube에는 OAuth 인증, API 호출 및 승인된 방송 송출에 필요한 정보가 전송됩니다. 현재 로컬 구성에서는 Google 데이터를 별도의 Live Studio 클라우드 서버에 업로드하는 기능을 제공하지 않습니다. Google 사용자 데이터를 판매하거나 광고·프로파일링 또는 AI 모델 학습을 목적으로 이용하지 않습니다. Google API 정보의 사용은 Google API Services User Data Policy의 제한적 사용 요건을 따르는 것을 원칙으로 합니다.

4. 저장 및 보호

현재 로컬 구성은 운영 데이터와 설정을 Windows PC에 저장하며, OAuth 토큰과 송출 키는 암호화 저장하도록 구성되어 있습니다. 관리자 인증은 평문 암호가 아닌 해시와 제한된 파일 접근 권한을 사용합니다. 원격 검증의 임시 갱신 토큰은 운영 DB에 저장하지 않도록 설계되어 있습니다. 같은 Windows 계정의 악성 프로그램이나 관리자 권한 공격으로부터 완전한 보호를 보장할 수는 없습니다.

5. 보관 기간 및 삭제

정보는 승인된 기능을 제공하는 데 필요한 기간만 보관해야 합니다. YouTube API에서 수신한 일반 데이터는 관련 정책이 요구하는 경우 30일 이내 갱신하거나 삭제해야 합니다. 권한 철회 또는 삭제 요청이 있으면 적용되는 YouTube API 정책의 기한에 따라 관련 저장 데이터를 삭제해야 합니다. 삭제 요청의 경우 가능한 한 신속하게, 늦어도 7일 이내 처리하는 것을 운영 기준으로 합니다. 삭제 기능과 보관 주기의 실제 구현 및 운영 절차는 공개 전 운영자가 확인해야 합니다.

6. 권한 철회 및 사용자 권리

  1. Google 계정의 타사 앱 접근 관리에서 Live Studio(동의 화면에 Studio로 표시될 수 있음)의 권한을 철회할 수 있습니다.
  2. 아래 연락처로 로컬에 보관된 연결 정보 및 YouTube API 데이터의 삭제, 열람 또는 정정을 요청할 수 있습니다. 계정 암호나 토큰을 메일에 보내지 마십시오.
  3. Live Studio의 저장 데이터를 삭제하는 것은 YouTube 자체의 방송이나 채널 데이터를 삭제하는 것이 아닙니다. YouTube의 데이터 삭제는 YouTube에서 직접 관리해야 합니다.

7. 쿠키 및 웹사이트

이 소개 사이트 자체는 로그인 양식, 광고, 분석 추적 스크립트 또는 쿠키를 사용하지 않습니다. 호스팅 제공자는 접속 로그 등 기술 정보를 자체 정책에 따라 처리할 수 있습니다. 로컬 Live Studio 앱은 관리자 인증과 승인 요청을 보호하기 위해 세션 및 쿠키 또는 유사한 인증 수단을 사용할 수 있습니다.

8. 변경 및 문의

데이터 처리 방식에 중요한 변경이 있는 경우 방침을 업데이트하고 필요한 동의를 다시 받습니다. 개인정보 관련 문의 및 삭제 요청은 아래 연락처를 이용하십시오.

Privacy Policy

1. Scope

This policy covers the Live Studio Windows application and this informational website. Live Studio uses YouTube API Services. Google’s handling of information is also governed by the Google Privacy Policy.

2. Information accessed and stored

  • Google OAuth connection details: access and refresh tokens, permission scopes, expiration and connection status.
  • YouTube API data: channel identifiers and names, broadcast and stream identifiers, status and binding details needed for broadcast management.
  • Local operational information: user-entered broadcast settings, schedules, media paths, stream keys, execution and diagnostic records.
  • Local administrator authentication: salted password hashes, sessions and one-time approval protection data.

Live Studio does not collect Google account passwords. Google sign-in takes place through Google’s authorization interface.

3. Purpose and sharing

Information is used to identify connected accounts, retrieve channel and broadcast details, manage user-approved operations, stream media and diagnose errors. Google and YouTube receive information necessary for OAuth, API calls and approved streaming. The current local configuration does not provide a separate Live Studio cloud service to upload Google data. Google user data is not sold or used for advertising, profiling or AI model training. Use of Google API information is intended to adhere to the Limited Use requirements of the Google API Services User Data Policy.

4. Storage and security

The current local configuration stores operational information on the Windows PC and is configured to encrypt OAuth tokens and stream keys at rest. Administrator authentication uses password hashes and restricted file access. Temporary remote-audit refresh results are designed not to be written to the operational database. These safeguards cannot guarantee protection against malicious software running as the same Windows user or administrators.

5. Retention and deletion

Information should be kept only as needed for authorized features. Ordinary YouTube API data must be refreshed or deleted within 30 days where required by the applicable policies. Data associated with revoked consent or a deletion request must be removed within the applicable YouTube API policy deadlines. Deletion requests are intended to be handled promptly and within seven days. The operator must verify actual retention, deletion functionality and operational procedures before publication.

6. Revocation and user rights

  1. Revoke Live Studio access (which may appear as Studio on the consent screen) through Google Account third-party access settings.
  2. Use the contact below to request deletion, access or correction of stored connection information and YouTube API data. Do not email passwords or tokens.
  3. Deleting Live Studio’s stored data does not delete data held by YouTube. Manage YouTube content and data through YouTube directly.

7. Cookies and website hosting

This informational site itself includes no login forms, advertising, analytics trackers or cookies. The hosting provider may process technical access logs under its own policy. The local Live Studio application may use sessions and cookies or similar authentication mechanisms to protect administrator access and approval requests.

8. Changes and contact

This policy will be updated for material changes in data handling and new consent will be requested where required. Use the contact below for privacy inquiries or deletion requests.
