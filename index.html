Live Studio

여러 유튜브 채널의 라이브 방송을
한곳에서 관리하세요.

Live Studio는 운영자가 권한을 보유한 YouTube 채널의 방송 준비, 예약 및 로컬 미디어 송출 관리를 지원하는 Windows 기반의 개인용 프로그램입니다.

A local Windows application for managing authorized YouTube channels, broadcast scheduling and media streaming.

Features

운영자를 위한 주요 기능

01 / CHANNELS

다채널 관리

여러 Google 계정에서 권한을 부여받은 채널과 방송·스트림 정보를 확인합니다.

방송 준비와 예약

Prepare schedules and manage approved broadcast operations.

FFmpeg를 이용해 선택한 미디어의 반복 재생 및 송출 상태를 관리합니다.

Manage local media playback and streaming status.

Google 계정과 YouTube API

Live Studio는 YouTube API Services와 Google OAuth를 사용합니다. 채널 조회와 승인된 방송 관리를 위해 필요한 권한을 요청하며, Google 계정 비밀번호를 Live Studio에 입력할 필요는 없습니다.

Live Studio uses YouTube API Services and Google OAuth to access authorized channel data and manage approved broadcast operations. Google account passwords are not requested by Live Studio.

이 사이트는 프로그램 소개 및 정책 안내용입니다. 프로그램은 현재 로컬 PC에서 개발·시험 중이며, 이 웹사이트에서 계정을 연결하거나 방송을 시작할 수 없습니다.
